# RF → AI → RF

**Скрипт пакетной обработки ветки mind-map в [RedForester](https://redforester.com) через LLM:**
забирает ветку по API, прогоняет текстовые узлы через Claude по заданному промпту
и собирает результат обратно в карту — зеркальной веткой, с сохранением структуры.

## Задача

В RedForester база знаний хранится в виде mind-map: дерево узлов, где узлы-категории
задают структуру, а текстовые узлы — содержание. Когда нужно единообразно переработать
целый раздел (переписать формулировки, привести к одному стилю, вытащить требования),
руками это десятки и сотни узлов.

Скрипт делает это одним прогоном: структура ветки сохраняется как есть, а содержание
каждого текстового узла проходит через LLM с промптом, который задаёт аналитик.

## Как работает

```
ссылка на ветку  →  разбор mapid/nodeid  →  рекурсивный обход дерева
                                                      │
                              ┌───────────────────────┴───────────────────────┐
                       узел-категория                                  текстовый узел
                              │                                               │
                 копируется как есть,                          текст очищается от HTML
                 структура сохраняется                          → уходит в Claude с промптом
                                                                → ответ становится новым узлом
                                                      │
                                        новая ветка создаётся рядом с исходной
```

- Обход дерева — рекурсивный, вложенность любой глубины сохраняется.
- Исходная ветка не меняется: результат пишется отдельной веткой в того же родителя,
  так что прогон всегда можно сравнить с оригиналом и откатить.
- Промпт подаётся `.txt`-файлом через диалог выбора файла — под каждую задачу
  свой промпт, править код не нужно.
- Каждый обработанный узел логируется в консоль, ошибки по отдельному узлу
  не роняют весь прогон.

## Стек

| Слой | Технологии |
|---|---|
| Язык | Python 3 |
| API-клиенты | `requests` (RedForester REST API), `anthropic` (Claude Sonnet) |
| Разбор контента | BeautifulSoup — очистка HTML из заголовков узлов |
| Интерфейс | `tkinter` — выбор файла с промптом |
| Конфигурация | `python-dotenv`, авторизация в RF по логину и MD5-хешу пароля |

## Структура проекта

```
app/
├── main.py              — CLI-сценарий: обход ветки, копирование и создание узлов
├── claude_connection.py — клиент Claude API
└── constants.py         — конфигурация и авторизация в RedForester
```

## Запуск

1. Клонировать репозиторий:

```bash
git clone https://github.com/moritys/rf-export-to-gpt-and-back.git
cd rf-export-to-gpt-and-back
```

2. Создать `.env` в корне по образцу `example.env`:

```
USER=your.login@example.com
PASSWORD=your_password
ANTHROPIC_API_KEY=your_api_key
```

3. Создать виртуальное окружение и поставить зависимости:

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirement.txt
```

4. Запустить:

```bash
cd app
python main.py
```

Скрипт попросит выбрать файл с промптом (`.txt`) и ввести полную ссылку на ветку, например:

```
https://app.redforester.com/mindmap?mapid=c04981ec-...&nodeid=cbf46d0c-...
```

> Claude API недоступен из России напрямую — запускать через VPN.
